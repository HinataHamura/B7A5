# GearUp

A responsive sports and outdoor gear rental frontend built with Next.js App Router, TypeScript, TanStack Query, React Hook Form and Zod.

## Setup

1. Copy `.env.example` to `.env.local` and set your backend URL.
2. Run `npm install` then `npm run dev`.
3. Set `NEXT_PUBLIC_DEMO_MODE=false` when connecting a real backend.

Demo accounts use password `Demo123!`: `customer@gearup.demo`, `provider@gearup.demo`, and `admin@gearup.demo`.
